# Ubuntu 虚拟机部署与每日启动

共享盘常见路径：`/mnt/hgfs/Small_s3/Charge_pile`。该盘往往是 `noexec`：虚拟环境、Hadoop、Qt 二进制都放在 `$HOME`，脚本始终用 `bash` 调用。

## 第一次（装环境）

```bash
bash /mnt/hgfs/Small_s3/Charge_pile/scripts/setup_all_ubuntu.sh
```

会安装 Java 11、MySQL、PySpark（可选）、Hadoop 3.3.6（RPC **8020**）、大屏 venv、机器学习查询 venv（仅 Flask），导入 `charging_screen.sql`，并生成：

```text
~/start_charge_pile.sh
```

只需快捷方式、不装软件时：

```bash
bash /mnt/hgfs/Small_s3/Charge_pile/scripts/install_start_shortcut.sh
```

家目录里的 `~/start_charge_pile.sh` **不会自动出现**，必须跑过上面两条之一，或跑过 `start_all.sh`。

## 以后每次登录

```bash
bash ~/start_charge_pile.sh                 # 大屏 + ML + 一期后端 + 已编译客户端
bash ~/start_charge_pile.sh --no-gui        # 只起后台
bash ~/start_charge_pile.sh --hadoop        # 同时 HDFS/YARN
bash ~/start_charge_pile.sh stop
bash ~/start_charge_pile.sh status
```

`setup_all_ubuntu.sh` 结束时会写入图形登录自启（只拉后台）。Tab 补全：`source ~/.bashrc`（由安装脚本写入 `~/.charge_pile_complete.bash`）。

## 只装二期 / 只起大屏

```bash
bash /mnt/hgfs/Small_s3/Charge_pile/scripts/setup_phase2_ubuntu.sh
bash ~/charging-bigscreen/deploy/phase2_services.sh start|stop|status
```

`SKIP_HADOOP=1` 可跳过 Hadoop 下载。`START_HADOOP=0` 或 `SKIP_HADOOP=1` 可让 `phase2_services.sh` 不拉 HDFS。

## 一期 Qt

Qt Creator 打开根目录 `ChargePile.pro`。编译一次后，`start_all.sh` 才能找到 `admin_server`。共享盘无法执行时复制到 `~/Charge_pile_bin`。

```bash
bash scripts/install_deps_ubuntu.sh
bash scripts/rebuild_run.sh
```
