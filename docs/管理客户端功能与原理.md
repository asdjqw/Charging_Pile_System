# 管理客户端（admin_client）功能与原理

> 代码行号基于当前工作区源码。管理端是 Qt Widgets 桌面程序，不直连数据库，
> 所有业务通过 TCP 长连接调用 `admin_server`，协议为「长度前缀 + JSON」。

## 一、文件结构与分工

| 文件 | 行数 | 职责 |
|------|------|------|
| `admin_client/main.cpp` | 51 | 程序入口：连接服务端、登录/主窗口循环 |
| `admin_client/LoginDialog.h/.cpp/.ui` | ~127 | 管理员登录、邀请码注册 |
| `admin_client/MainWindow.h/.cpp/.ui` | 1254 | 主工作区：8 个功能页的全部交互 |
| `admin_client/AdminApiClient.h/.cpp` | 363 | 唯一网络层：socket、协议、全部 RPC 封装 |
| `admin_client/EditPileDialog.ui` | — | 新增/修改电桩表单布局 |
| `admin_client/EditStationDialog.ui` | — | 新增/修改电站表单布局 |
| `admin_client/UserOrdersDialog.ui` | 32 | 用户充电记录弹窗布局 |
| `common/StyleHelper.h` | 515 | QSS 样式（无独立 .qss 文件） |
| `common/FramedJson.h/.cpp` | — | 长度前缀 JSON 帧编解码（粘包处理） |
| `common/JsonCodec.h/.cpp` | — | 业务结构体 ↔ QJsonObject |
| `common/Models.h` | — | User/Admin/Station/Pile 等结构体 |

调用链：

```
main.cpp → LoginDialog → MainWindow（界面、事件）
                ↓ 全部只调用
        AdminApiClient::xxx()（业务 API）
                ↓
        AdminApiClient::call()（组包/发帧/等响应）
                ↓
        QTcpSocket + FramedJson → admin_server
```

## 五、网络层 `AdminApiClient.cpp`（363 行）

### 5.1 基础设施

| 行号 | 函数 | 功能与原理 |
|------|------|-----------|
| 11–15 | `instance` | Meyers 单例：全进程一条连接、一份 token |
| 23–28 | `initialize` | 记录 host/port（默认 `127.0.0.1:9000`）并连接 |
| 35–48 | `ensureConnected` | 已连直接返回；否则 `abort()` 清缓冲重连，等 3 秒 |
| 50–103 | `call` | **核心**：组 `{version, requestId, action, data, token}` → `FramedJson::encode` 加长度前缀发出 → 8 秒内按 `requestId` 匹配响应；先到的其它响应暂存 `m_queuedResponses` |
| 105–119 | `accept` | 检查 `ok` 字段；失败记 `lastError`/`lastCode`；`UNAUTHORIZED` 时清 token 强制重登 |

**协议原理**：TCP 是流式无边界，`FramedJson` 用 4 字节长度头切帧解决粘包；`requestId`（UUID）解决响应乱序归属。

## 六、关键设计小结

1. **页面切换**：侧栏 `QListWidget` 下标与 `QStackedWidget` 页下标一一对应，一条信号完成全部导航，避免 8×8 的两两连槽。
2. **数据刷新**：无缓存、无推送、无轮询；切页/点刷新/写操作成功后重新拉取，表格即当次请求结果。
3. **级联刷新**：改桩/站后同时刷新桩表、状态页、电站表，保证各页数字一致。
4. **强制删除**：服务端返回 `NEED_FORCE` 时客户端二次确认后带 `force=true` 重发。
5. **样式与布局分离**：`.ui` 管控件树，`StyleHelper.h` 管 QSS 配色，`.cpp` 管行为。
6. **通信封装**：界面层不碰 socket，全部经 `AdminApiClient` 单例同步 RPC，错误统一走 `lastError()`。
