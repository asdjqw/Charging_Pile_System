# 管理客户端：功能与原理

管理端是 Qt Widgets 程序，**不直连数据库**。所有动作经 `AdminApiClient` → 长度前缀 JSON → `admin_server`。

## 文件

| 文件 | 职责 |
|---|---|
| `admin_client/main.cpp` | 连 TCP、登录循环、默认最大化 |
| `LoginDialog.*` | 管理员登录、邀请码注册 |
| `MainWindow.*` | 侧栏 + 堆叠页 |
| `AdminApiClient.*` | 唯一网络层 |
| `common/ForecastDialog.*` | 预测图表面板（`ForecastPanel`）与弹窗 |
| `common/StyleHelper.h` | QSS |

默认连接 `CHARGE_PILE_HOST` / `CHARGE_PILE_PORT`（`127.0.0.1:9000`）。连不上 `admin_server` 会直接退出。

## 侧栏与页面（必须按下标对齐）

`onNavChanged`：`m_stack->setCurrentIndex(row)`。增删页时 **侧栏 item 顺序、stack 子控件顺序、switch case 必须一起改**。

| 下标 | 侧栏 | 刷新函数 |
|---:|---|---|
| 0 | 销售业绩 | `refreshDashboard` |
| 1 | 电桩状态 | `refreshPileStatus` |
| 2 | 充电桩管理 | `refreshPiles` |
| 3 | 充电站管理 | `refreshStations` |
| 4 | 充电预测 | `refreshForecastPage` |
| 5 | 评价管理 | `refreshReviews` |
| 6 | 用户管理 | `refreshUsers` |
| 7 | 预约管理 | `refreshReservations` |
| 8 | 权限管理 | `refreshPermissions` |

评价管理以前文案是「评论管理」，页面一直在，不是被删了。充电预测以前只在电站页一个按钮上，侧栏看不到。

## 充电预测

1. 侧栏「充电预测」：选电站 →「查询预测」。
2. 「充电站管理」点一行再点「充电预测」：跳到第 4 页并查询。

TCP：`admin.forecast.station`，权限 `stations.read`。后端 `MlForecastGateway` 访问 `CHARGE_PILE_ML_URL`。需要本机 `:5010` 已启动，否则弹接口错误。

## 其它页要点

- 电桩「模拟维修」只在选中故障桩时出现。
- 权限页改的是 **operator / auditor** 角色权限，不是当前登录人的菜单显隐；管理员账号默认全开。
- 主题：`StyleHelper::adminClientStyle()`，侧栏深色；用户端那套 `QListWidget::item` 边距不要盖住侧栏项（已用 `#sideNav` 覆盖）。

## 编译注意

`admin_client.pro` 需要 `QT += charts`，并编译 `common/ForecastDialog.cpp`。改 `.pro` 后 Run qmake。
