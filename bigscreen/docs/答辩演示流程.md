# 答辩演示流程（约 10 分钟，按当前仓库）

不要念已经不存在的 IP `192.168.44.129` 或 `systemd charging-screen`（除非你自己执行过 `bigscreen/deploy/install_service.sh`）。

## 0. 开机

```bash
bash ~/start_charge_pile.sh --no-gui
# 需要现场秀 HDFS 时加上 --hadoop
```

Qt 一期：再开 Creator 或去掉 `--no-gui`。分析大屏：**http://127.0.0.1:5000/**

## 1. 大屏结果（2 分钟）

指顶部 KPI、负荷、热力、站点 TOP、工作日/周末、用户分层、电池、滚动订单。一句话：Spark → MySQL → Flask → DataV。

## 2. 清洗（2 分钟）

```bash
head -2 ~/charging-bigscreen/data/raw/nvv2t.csv    # 年份 0014
curl -s http://127.0.0.1:5000/api/quality | head
```

讲年份修复、异常剔除、遥测时间丢弃、电流幅值。

## 3. Hadoop（2 分钟，可选）

```bash
source ~/charging-bigscreen/deploy/hadoop_env.sh
jps
hdfs dfs -ls /data/charging
```

说明：大屏读 MySQL；HDFS 是离线层。RPC 是 **8020** 不是 9000。

## 4. 接口（1 分钟）

```bash
curl -s http://127.0.0.1:5000/api/health
curl -s http://127.0.0.1:5000/api/screen/bundle | head -c 200
```

## 5. 一期 + 预测（3 分钟）

- 管理端 `admin/123456`：评价管理、充电预测（需 `:5010`）。
- 用户端 `13800001111`：找站、预约/充电、详情里充电预测。
- 说明预测是三个目标小时，演示数据可能是 `SIMULATED`。

## 不要做

- 不要打开 `:8080` 当分析大屏。
- 不要现场对 3.10 安装整份 `ml/requirements.txt`。
