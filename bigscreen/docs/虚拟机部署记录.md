# 虚拟机部署记录（本仓库约定）

旧稿记录的是另一台机器上的 nginx + systemd `charging-screen`、HDFS `bitdev:9000`。**不要照抄 IP 和端口。**

## 推荐状态

| 项 | 约定 |
|---|---|
| 系统 | Ubuntu 22.04，普通用户（如 `bit`），不要 `sudo bash` 整份安装脚本 |
| 工程 | 共享盘 `/mnt/hgfs/Small_s3/Charge_pile`，运行时同步到 `$HOME` |
| 安装 | `scripts/setup_all_ubuntu.sh` |
| 日常 | `bash ~/start_charge_pile.sh` |
| 大屏 | Flask `127.0.0.1:5000`，库 `charging_screen` |
| Qt | TCP 9000，HTTP 8080 |
| ML 查询 | 5010，venv `$HOME/charging-ml-venv` |
| Hadoop | 3.3.6 伪分布式，RPC **8020**，`/data/charging` |

## 踩坑（仍然有效）

1. 共享盘 `noexec`：venv、Hadoop、Qt 二进制放 `$HOME`。
2. 系统是 `python3` 不是 `python`。
3. 分析大屏入口是 **5000** 不是 8080。
4. HDFS 不要占用 9000。
5. `ml/requirements.txt` 不适合 Ubuntu 自带 3.10。
6. 家目录快捷方式不会凭空出现，先 `install_start_shortcut.sh` 或完整 setup。

可选：在 `~/charging-bigscreen` 执行 `bash deploy/install_service.sh` 才会有 nginx 80 与开机 systemd。未做这一步就不要在答辩里说「80 端口 nginx」。
