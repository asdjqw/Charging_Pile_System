# 答辩要点（分析大屏）

整体项目还有 Qt 一期和 ML 预测，入口与端口见仓库根 `README.md`。本文只准备**大屏 5 分钟口述**。

## 一句话

对订单、遥测、站点三张表做 Spark 清洗和 15 维分析，结果进 MySQL，Flask 出接口，Vue3 + DataV 展示；原始文件和结果可以放在 Hadoop（本仓库 NameNode **8020**）。

## 清洗（讲「为什么」）

1. 年份 `0014-11-18`：用星期独热列交叉验证后统一 +2000 到 2014。
2. 0 电量、超长时长等异常订单剔除约 56 条，质量面板可展示原因。
3. 遥测 `record_time` 为科学计数，有效数字丢失，字段丢弃。
4. 电流取幅值；派生功率、单价、压差、温升、峰平谷。
5. 遥测与订单按会话号关联（原始集约 98.8%）。

## 15 维 / 5 组对比

KPI、日/月趋势、24h 负荷、星期×小时、站点排行、行政区、站型、工作日 vs 周末、峰平谷、用户 RFM、时长/电量/功率分布、电池健康、收入与平台。

## 扩容后可讲的数（约 2014-11-18～2015-10-04）

- 有效订单约 **54944**，电量约 **327758 kWh**，活跃用户 **2556**。
- 高价值用户约 34% 贡献约 **88%** 电量。
- 直流站电量约 52.7%；四类站桩均订单接近。
- 工作日与周末日均订单接近（扩容前周末样本极少，不能拿原数讲「周末没人充」）。

原始未扩容结论（105 站、3339 单）数字更小、周末/谷段更极端，答辩前确认大屏连的是哪套库。
